# Landing Page - Chai Ghar

A responsive static landing page for a fictional chai subscription brand.

## Tech Stack
HTML5, CSS3 (Flexbox + Grid). No JavaScript.

## Features
- Sticky navigation bar with 3 links
- Hero section with headline, subheadline and call-to-action button
- Features and Reviews sections
- Footer with contact and social placeholder links
- Consistent colour palette (green, saffron, mist)
- Responsive layout for mobile screens
- Two font sizes for headings and body text

## How to run
Open index.html in any browser.
